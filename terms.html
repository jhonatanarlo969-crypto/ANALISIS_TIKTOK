Términos de Servicio

Última actualización: 2026.

1. Aceptación de los términos

Al autorizar esta aplicación mediante el inicio de sesión de TikTok, el usuario acepta estos términos de servicio.

2. Descripción del servicio

Esta aplicación es una herramienta personal de análisis que se conecta a la API de TikTok para obtener métricas del contenido publicado por el propio usuario (vistas, likes, comentarios, compartidos y fechas de publicación), con el fin de generar reportes y estadísticas.

3. Uso permitido

Esta aplicación está destinada únicamente para uso personal del propietario de la cuenta de TikTok conectada. No debe usarse para acceder a datos de cuentas de terceros sin su consentimiento.

4. Limitación de responsabilidad

El desarrollador no se hace responsable por interrupciones del servicio derivadas de cambios en la API de TikTok, ni por el uso indebido de los datos por parte del usuario final.

5. Modificaciones

Estos términos pueden actualizarse en cualquier momento. El uso continuado de la aplicación implica la aceptación de los cambios.
